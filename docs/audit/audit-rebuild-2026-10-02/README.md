## 工作与保存方式

四条工作线围绕同一模块协作：源码审计、最小修复、独立复核、安全精简。图解析、计划文档和历史数字不计为本轮源码覆盖。新增补丁的审阅和fake测试与基线函数覆盖分开记录。

每个代码批次验证冻结源码/测试/补丁哈希，建立单父提交，以非force方式更新此分支，再逐文件读回。文档和日志拆成小批次保存；原始覆盖证据保留，报告链接随证据保存逐步补齐。源码修复优先于辅助报告，不改写既有历史。
