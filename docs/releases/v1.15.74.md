# 1.15.74

## Fixed

Current Hermes v0.23.0 still imports `packaging.requirements` while loading plugins. It did not drop the module; `pyproject.toml` pins `packaging==26.3` for Python 3.14.

The host verifier runs the eimemory release interpreter with `-I`. That interpreter is built from `eimemory[hermes]`, which previously installed only PyYAML and ruamel.yaml. Plugin discovery then raised `ModuleNotFoundError: No module named 'packaging'` after the current link switched, and the installer rolled back.

`eimemory[hermes]` now installs `packaging==26.3`. The staged import check fails before switch if that module is absent.
