# eimemory 1.15.80 — merge RAW ranking gains into ordinary-chat temporal release

## Scope

This release merges the previously isolated RAW relevance-ranking candidate into the shipped 1.15.79 ordinary-chat valid-time baseline. It does not replace or disable that temporal integration. Existing native source/scope admission, canonical hydration, full-digest checks, collection deadlines and temporal behavior remain required.

The ranking helper adds topic-aware lexical relevance and bounded entity/attribute matching instead of letting unrelated recency or correction words dominate retrieval. The merge repairs legitimate Chinese and English changes, correction preambles and quoted-entity boundaries, while retaining protections against another entity, attribute or sentence borrowing the query's identity. Numeric identifiers and explicit historical intent remain meaningful.

The adapted upstream contribution retains its MIT attribution in `eimemory/raw/KROUTER_NOTICE.txt`. No additional database, production data migration, credential change, model-route change or other-profile configuration is introduced.

## Measured acceptance

Same original public fixture: 110 Markdown pages, 200 questions, identical import mapping and scorer, 120 answerable and 80 no-answer questions. No final answer model is used in this RAW retrieval comparison.

- Answerable Top-1: **109/120 (90.833%)**, compared with **61/120 (50.833%)** for the shipped 1.15.79 baseline.
- Answerable Top-5: **119/120 (99.167%)**, compared with **99/120 (82.5%)**.
- Correction subset: **54/60**; current-fact subset: **55/60**.
- No-answer correct empty retrieval: **0/80**, unchanged. Overall strict score is therefore **109/200 (54.5%)**, not 90.833% over all questions.
- Same-run KRouter reference: Top-1 102/120, Top-5 104/120, correct empty retrieval 47/80 and overall 149/200. This release improves answerable ranking, not every dimension of the reference system.
- All 200 question IDs were present for each system, no retrieval execution errors occurred, and aggregates were independently recomputed from per-query results.

The public questions are seen regression data, not blind independent production evidence. The original 16 parent ranking cases now pass 16/16. A newly frozen eight-case set passes 8/8; three of those examples were exposed during directed repair and are now seen regressions, so the whole set must not be advertised as blind.

Consolidated parent execution on the frozen business code: **1045 tests and 89 subtests passed**. One original real-LoCoMo-data check skipped because `locomo10_eimemory.json` is absent; that data-dependent behavior is not certified. Ordinary-chat temporal regressions are included. Tests and source review do not themselves prove deployment or live host acceptance.

## Limits

The unchanged 0/80 no-answer result remains an explicit RAW rejection-policy shortfall. It is not an estimate of final-model hallucination, and no blanket threshold was added to inflate refusals at the expense of answerable queries.

This is not general end-to-end model-answer accuracy, production-profile latency, 48-hour stability or L5 certification. Formal immutable deployment and read-only post-switch receipts remain separate requirements. The already excluded old-binary rollback-compatibility branch is not restored by this merge.
