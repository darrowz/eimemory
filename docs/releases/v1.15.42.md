# 1.15.42

Semantic repair now completes a replay and its independent review before admitting more replay work. Incident and packet positions persist across releases, and admission alternates with existing reviews so repeated failures cannot monopolize the shared budget.

Recovered evidence can be retried without changing capture policy. Incomplete retrieval or changed current result authority can create a new signed replay attempt under the same release. The new attempt links its predecessor; the old packet and verdict remain unchanged. Unchanged evaluated negative results reuse their review without another model call. Scope, source, signature, historical render and current release checks still precede repair credit, and native intake closes only the exact current incident atomically.

Replay, review and collection serialize participating callers before real work. Receipt deduplication therefore also protects concurrent successful calls. No model routing, per-call budget or natural-sample authority changes.

This release does not turn real off-topic or unknown judgments into passes. Missing historical inputs remain unverifiable. A current-release replay and model review require two work units; a single one-unit invocation per release cannot complete both.
