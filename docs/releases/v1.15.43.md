# 1.15.43

A faithful replay that completed with no evidence remains unresolved. It no longer creates an automatic chain of identical replay attempts under the same release. Incomplete retrieval, unknown state, budget exhaustion and changed result authority retain their existing bounded retry path. Explicit linked attempts remain available after an actual corpus repair; historical packets are preserved.

New signed packets retain numeric candidate and selector input, selected and dropped counts. Missing stage counters stay unknown. No threshold, index rebuild, model routing, production configuration or repair acceptance gate changes.

These changes do not establish recovery of real off-topic, unanswered or unknown cases. Those require original-case replay and independent current-release acceptance before closure.
