# eimemory 1.15.68

## Summary

RelevanceAdmission grounded-backoff: when `EIMEMORY_RERANKER_ENABLED=1`, post-fusion selection now runs local grounding first. If grounding finds evidence, that result is kept; only an empty grounding pool falls back to fused-order Admission select. This restores production_recall gold ranking (mrr/jaccard) under Admission without giving up rewrite-empty unlocks.

## Why

Tip 1.15.67 with Admission ON short-circuited past local grounding. Controlled benches stayed green, but production_recall gold `mem_778b…` dropped out of top-5 (mrr 0.67→0) and nightly `memory_eval_ci` failed. Gate-only rebaseline cannot accept mrr=0.

## Change

- `GovernedRecallEngine._select_post_fusion_items`: RelevanceAdmission path uses grounded-backoff; LightweightAdmission unchanged.
- Report fields: `hybrid_policy` (`grounded_backoff_kept_grounded` | `grounded_backoff_admission_fill`), `admission_used`.
