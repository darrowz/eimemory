# 1.15.77

- L1 健康统计改用一次锁内验证的快照，保留 `dead` 历史计数，增加 `unresolved_dead`、`active_recoveries`、`completed_recoveries`、`failed_recoveries`。未解决数按 retained dead 条目计算；耗尽恢复的原条目和子条目均保留。有效完成账本加最新健康 worker 观察才能解除降级；缺失或未知状态不冒充零健康。
- RPC 500 仅增加固定 `stage` / `exception_family`，不记录动态异常名、消息、请求正文、绝对路径或堆栈。原认证、拒绝、HTTP 状态及有界日志隔离不变，不能据此追认历史原因。
- 未改 Hermes 生命周期所有权或 capture 授权。父级负责审核、回归与正式部署；实现测试不代表生产修复、L5、48 小时或自然质量验收。
