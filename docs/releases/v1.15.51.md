# 1.15.51

Linux filesystem fault tests now use a shared module-private standard-library boundary, including publicly imported storage transaction helpers. Injected stat, descriptor and write failures cannot replace the process functions used by pytest. Existing rejection, durability and cleanup assertions remain enforced.

This release carries forward 1.15.50 and 1.15.49. Four-case recall configuration and quality repair remain open; this change does not establish CI success, deployment acceptance or L5 completion.
