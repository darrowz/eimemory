# 1.15.50

Snapshot filesystem tests now inject failures through a module-local OS namespace. This prevents the injected descriptor and path functions from corrupting pytest output capture and cleanup. Ancestor replacement rejection and descriptor closure assertions remain unchanged.

This release includes 1.15.49 proposal wiring preflight and faithful single-source target tracing. It does not establish four-case recall repair, nightly success, deployment acceptance or L5 completion.
